# TrayScroll
Key to Scroll, supports Page Up/Page Down/Up/Down, best for devices without mouse.

>[!warning]
>This tool, will be built-in to LunaClean v3. Better option, wait before LunaClean v3 and install it.

### Building:

- Rustc and Cargo required:
`rustc --version`
,
`cargo --version`

- Build:
`cargo build --release`
